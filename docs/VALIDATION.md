# Проверка базового MVP

Дата: 15 октября 2026. Проверялся исходный сервер без изменения игровых правил. Это отчёт о текущем коде; целевые требования находятся в [PRD.md](PRD.md).

## Выполнено

- `npm ci --ignore-scripts`: зависимости установлены из lockfile.
- `npm run check`: синтаксис сервера и браузерного клиента проверен.
- `npm test`: локальный сервер и независимые WebSocket-клиенты; все перечисленные ниже проверки прошли.

## Установлено чтением кода

- Список содержит 216 записей, 210 уникальных написаний. Это тестовый список, а не полный проверенный словарь.
- При отказе в апелляции выдаётся новый полный таймер; срока решения и лимита апелляций нет.
- В командах нет проверки абсолютного дедлайна; завершение зависит от фонового таймера.
- Старое соединение игрока после повторного входа не отзывается; его закрытие может испортить индикатор подключения нового.
- Сопоставление конечных букв используется и для словаря, поэтому отдельная строгая проверка написания отсутствует.
- Stop до времени старта сервер отдельно не отклоняет; готовность не проверяет наличие обоих живых соединений.
- Реванш запускается одним участником; отдельного согласия второго нет.
- После перезапуска комнаты исчезают; постоянное хранилище отсутствует.

## Ещё не проверено

Работа на двух реальных телефонах, внешний WSS через Render, задержки в мобильной сети, соблюдение дедлайна под нагрузкой, сценарии апелляции из целевого PRD, нагрузка 20 комнат, качество полного словаря и все критерии AC-01–20 целиком.

GitHub-репозиторий и Render-сервис в этой сессии не созданы. Для публикации нужны доступ на запись в GitHub и явный выбор рабочего пространства Render.
